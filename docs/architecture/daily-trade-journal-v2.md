# daily-trade-journal v2 架构报告

## 已批准方向与本轮范围

2026-09-03 已批准将 `daily-trade-journal` 收敛为一个以用户叙述为中心的普通 Obsidian Markdown 记录入口，而不是机器计划对齐、交易执行器或账户看板。本轮只调整 Skill 入口、界面提示、说明文档和本文件；既有 helper scripts、测试和真实记录均不改。

记录保留两组：`持仓管理` 与 `计划买入`。每个标的只记录交易工具和具体想法；触发、退出、加仓或减仓条件有则自然写在想法中，不增加必填字段。期权方向写英文 `Call` / `Put`。不强制结果评价、固定问卷或机械计划内外标签。

## 日常与周末工作流

日常先读取 `25 投资交易` 中的当前计划记录、相关旧日记和当天旧记录，再听用户本次叙述。已有回答不重复问，只追必要缺口；没有当日用户叙述就不自行编日记。若只有旧不可变计划版本而没有普通计划落点，先向用户确认目标和承接范围，不静默迁移。

用户自述可以如实记录，但必须与独立核验的成交、持仓或行情事实区分。券商数据暂缺时仍可继续记录想法；缺数据不能被写成无成交或持仓结论。未实施的想法可以继续有效，已买入不代表持仓管理结束，跨周有效内容沿用，不自动清空或失效。未来动作保留“考虑”“可能”等原语气，不自动升级为确定执行；新建或修订只在展示具体内容并得到用户确认写入后保存，不强制新版本或 schema。

周末支持生成本周行为回顾，只回顾已发生的操作和计划实施，区分已实施、仍等待和缺少证据。继续有效的计划跨周沿用；只有用户确认作废，才单独展示对象并归档到现有私有知识库。归档不直接删除或自动失效，也需要独立确认。

## 技术面与数据边界

只有用户讨论某个标的且需要参考时，才提供轻量支撑、压力或条件判断。默认使用真实来源的已完成 1D 日线，并注明来源和截至时间；不足就说不能判断。目标价不是已验证压力位，触价不是成交，日线结果不是小时验证；用户自行查看小时级别，口述小时观察只作为自述。本轮不跑技术分析，不引入下载器或依赖；已有只读行情、成交或合约辅助能力可按需保留，但不是普通日记的前置条件。

继续使用 `25 投资交易/10 每日复盘`、`25 投资交易/20 周度复盘` 和 `25 投资交易/30 已确认计划摘要`。先发现现有落点，不臆造真相源，不静默改历史版本。沿用既有隐私边界：不访问账户、盈亏、下单接口、凭据、SQLite、Web UI 或 Bridge；账户、原始券商响应和敏感期权身份不进入仓库、普通日志或公开日记。具体期权合约仅在已有且明确授权的私有预览边界内处理。

## 写入、失败与回滚

先展示具体 Markdown 草稿，用户明确回复“确认写入”后才保存；无变化为 `no_op`。写入前保留可恢复的原版本，重读 live 文件并检查并发；未开始写时如有冲突，保留原文并停止。已有 managed 日记只在既有 managed 边界内更新；没有 managed 的普通计划笔记只改用户确认的段落，保留其他手写内容，不强制新建 managed 区域。写后先文件系统回读，再顺序进行 Obsidian CLI 回读；回读失败就停止后续写入并报告写入未验证，不宣称成功或自动回滚。需要回滚时先重读，发现新修改不得覆盖。

| 阶段 | 失败或未知 | 处理与回滚边界 |
| --- | --- | --- |
| 读取 | 计划记录、旧日记或可用事实缺失 | 保留自述与缺口的区别，不把缺失升级为事实；等待用户补充 |
| 写入 | 未确认或未开始写时并发变化 | 不写并保留原文 |
| 写入后 | 隐私或回读失败 | 停止后续写入，报告写入未验证，不宣称成功或自动回滚；需要回滚时先重读，发现新修改不得覆盖 |
| 归档 | 用户未明确确认作废 | 不归档、不删除、不自动失效 |
| 技术参考 | 日线未完成、来源/时间不足 | 不编支撑压力；小时内容仅保留为用户自述 |

旧 immutable 版本保留作只读历史参考；本轮不原地覆盖、不迁移真实记录，迁移状态为 `NOT RUN`。本轮未改 helper scripts；不把旧程序描述成普通记录引擎。

## 证据与状态分离

| 证据层 | 本轮状态 |
| --- | --- |
| Skill、界面提示和文档实现 | 本轮修改范围内 |
| 本地 automated checks | 与实现结果分开回传 |
| 真实行情读取 | `NOT RUN` |
| 真实 Obsidian 写入 | `NOT RUN` |
| 真实计划迁移 | `NOT RUN` |
| 定时任务配置或同步 | `NOT RUN`，需另获授权 |
| 人类功能验收 | `PENDING` |

本地测试、Skill validator、配置读回和 Git diff 只证明对应的本地约束，不能升级为真实行情、真实写入、迁移、调度或人类验收。任何 `blocked`、`PENDING`、`NOT RUN` 或 `no_op` 都原样保留。

# 交易复盘分析路由

本项目的正式分析只使用 Longbridge 已验证事实和项目内已经确认的计划。Codex 是唯一的分析编排者：它可以整理事实、解释风险、对照计划和生成条件式检查，但不能读取券商凭据、替代确定性脚本或新增数据源。

## 1. 路由表

| 需求 | 确定性事实 | Codex 输出 |
| --- | --- | --- |
| 每日盘前复盘 | 前一交易日订单/成交、当前账户/持仓快照、Longbridge 市场字段、当前周计划 | 核心判断、主要风险、条件式执行检查、缺口 |
| 实际交易复盘 | 已授权窗口内的订单/成交聚合、快照净变化、已确认计划 | 计划 vs 实际、勾稽边界、纪律复盘 |
| 周度复盘 | 明确授权的整周账户、订单/成交、盈亏和市场字段 | 周初/周末对比、本周过程、下周计划草案 |
| 计划核对 | 周度基线和已确认每日增量、当前持仓映射 | 覆盖、触发距离、失效条件和下一步检查 |

没有对应 Longbridge 事实时，Codex 只能输出“未验证”或“阻塞”，不能用训练记忆、用户口述、旧快照或其他提供商补齐。

## 2. Longbridge 能力分层

每次运行分别检查以下能力，并记录 available、unauthorized、not_installed、missing 或 stale：

- broker-live：assets、positions、order history、order executions history。
- market：quote、capital、market-temp；经用户明确批准的 LongbridgeAI 收盘分析 Skill。
- calendar：finance-calendar、macrodata。
- performance：profit-analysis。

一个能力可用不代表其他能力可用。能力检查通过也不等于数据完整、账户完整或已经对账。

## 3. Codex 分析输入

送入 Codex 的内容必须是本地确定性脚本生成的脱敏固定字段包，至少包含：

- 数据状态和时间戳。
- Longbridge 来源范围。
- 当前账户和持仓的允许聚合。
- 前一交易日订单/成交的允许聚合。
- 当前周已确认计划和每日增量。
- 相关事件视图。

禁止把原始券商响应、完整日历、账户标识、订单/成交 ID、凭据、成本或佣金交给分析层。

## 4. Codex 分析输出

输出顺序固定为：

1. 确定性事实。
2. 对事实的解释。
3. 主要风险。
4. 条件式执行检查。
5. 失效条件和证据边界。
6. 未验证缺口。

条件式检查必须使用 if、then、else、evidence_refs、boundary 五个字段。then 只能引用已确认计划中的动作或验证步骤；不得新增无条件买入、卖出、加仓或减仓指令。

如果分析失败：

- 保留确定性事实。
- 将分析模块标为 partial 或不可用。
- 写明脱敏失败类别。
- 不把空摘要当作成功。

## 5. 市场和计划边界

- quote 只证明 Longbridge 返回的真实标的或代理的行情。
- capital 只称为标的资金流，不能扩展成全市场资金流。
- market-temp 只作为 Longbridge 市场字段，不能单独生成风险偏好结论。
- 收盘市场环境在六个固定代理的同一 review_date 完成日线齐备时，使用用户已批准的 LongbridgeAI 公共分析 Skill 和固定收盘提示生成结构化结论、最多三条支持事实及下一交易日验证条件；原始回答和引用不进入展示。不能把同日价格变化写成宏观因果，也不能用盘前/夜盘 quote 更新该结论。
- finance-calendar 和 macrodata 的事件必须经过相关性筛选。
- 计划、候选池和 Codex 判断都不能替代实际成交事实。
- 当前持仓快照不能替代历史持仓、收盘持仓或整周对账。

## 6. 缺口处理

| 缺口 | 处理 |
| --- | --- |
| Longbridge 能力不可发现 | 标记 not_installed 或 missing，不擅自安装 |
| 权限不足 | 标记 unauthorized，不调用未授权接口 |
| 返回结构不完整 | 标记 partial 或 blocked，保留错误类别 |
| 成功空数组 | 标记 empty，并明确是接口成功返回 0 条 |
| 时间超过新鲜度 | 标记 stale，保留原始时间 |
| 关键字段或隐私校验失败 | 标记 blocked，不生成成功看板 |

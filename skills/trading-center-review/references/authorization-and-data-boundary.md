# 授权与数据边界

## 默认边界

- 可读：当前项目中不含私有券商数据的约定、模板、研究和用户在对话中主动提供的信息。
- **Longbridge 持仓允许例行只读同步**：本交易中心工作流已启用 `positions --format json` 的最小持仓快照同步。同步只保留在 Git 工作树外的私有运行目录，用于每日/周度复盘输入；不因此获得 Longbridge 成交、订单、利润、对账单或凭据的读取权限。
- Longbridge 成交/订单/资金、凭据、Cookie、API key，以及任何未在本线程明确授权的私有文件仍不可读；本流程不提供其他券商接入。
- 不可做：下单、改撤单、调用券商交易接口、把私有券商数据写入 Git、对外发送交易信息。

## 授权判断

接受的最低授权须同时指出“Longbridge（或其他明确来源）”“读取”“本地导出文件/具体路径”及“本线程”。泛泛的历史授权、登录状态或“帮我复盘”均不构成数据读取授权。

Longbridge 持仓同步授权只允许读取当前快照，不能外推为：历史持仓完整性、跨账户汇总、成交/订单/资金读取、交易操作、Wiki 写入或公开分享。

## 外部写入

飞书 Wiki 写入是独立授权：先给出本轮 `run_id`、目标空间/节点、拟写入标题和正文摘要，用户确认后再写。自动化创建的新复盘对话可在**本对话**内取得并使用该确认，不需要转交主对话；但定时触发本身不构成写入许可，确认也不得外推到另一 `run`、另一目标节点或未展示字段。只读查看 Wiki 不等同于写入许可。

## 调度边界

定时提醒可以请求用户完成复盘或提供资料；按本工作流启用的 Longbridge 持仓同步只执行最小只读快照，不把“定时”外推为 Longbridge 其他接口或 Wiki 写入授权。创建、更新或删除自动化前，先检查已有自动化并让用户确认具体的重复规则、时区和目标对话。

## 输出位置

导入后的原始文件和含明细的草稿应位于用户指定的私有运行目录，不在项目 Git 工作树内。项目内只保留 Skill、空白模板、脚本和脱敏示例；如果输出路径位于 Git 工作树，停止并要求新的私有路径。

## 密钥与模型

仅当用户已确认具体摘要任务允许使用 AI，且即将执行该调用时，才读取用户指定的密钥文件。不要列目录以搜索密钥，不要把密钥放入环境输出、命令行回显、日志、草稿、Wiki 或 Git。模型标识、端点和数据是否可发送给该服务都需要在首次调用前确认；“可使用 AI”不等同于允许发送原始券商明细。

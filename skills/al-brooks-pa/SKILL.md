# Al Brooks Price Action 分析

这是独立的 PA 分析入口，只处理用户已经筛选的标的。它不选股、不做基本面研究、不下单、不管理账户、不写 Obsidian，也不调用 technical-analysis、mars-research-assistant 或其他研究 Skill。日线负责判断 Cycle、位置、量价及 EMA10/20；盘中操作只依据已完成 1H K 线。没有可用的已完成 1H 时，只能更新观察条件，不能确认盘中买入、加仓、减仓或退出。

## 路由

1. 每次先读 references/pa-framework.md，按其中的数据门禁和内部顺序执行：数据事实 → 日线 Cycle 与市场状态 → 量价和 EMA10/20 → 位置门槛 → setup → 已完成 1H signal bar / follow-through → 条件化分支 → measured move → 失效与重新评估 → 盘中关注要点。
2. 识别 wedge pop、突破后整理、回踩二次进场、extension / buy climax 或其他具体形态时，再读 references/setup-catalog.md；不要为了填表给没有证据的结构命名。
3. 需要套用已确认的表达偏好时读 references/personal-trading-profile.md。它只提供脱敏偏好，不提供行情、持仓或执行事实。

## 证据与输出边界

- 分开写用户自述、数据事实、分析推断和缺口；每个关键事实注明 source、as_of、period 与 candle_status（completed、forming 或 unknown），并注明价格、成交量及 EMA10/20 是否来自同一数据口径。盘前价格和形成中 K 线只能改变观察状态，不能确认突破、signal bar、follow-through 或结果。
- 默认只研究单边做多。下跌分支用于描述不买、等待重新构造、减仓或退出，不自动生成 Put 或做空计划；只有用户另行明确确认的独立计划才例外。
- 到达关键位置不是买点。每个买入候选都必须分开写位置门槛、已完成 1H 做多信号 K、需要的跟随或突破方式，以及失效后如何等待。signal bar 只进入买入考量，不自动等于成交授权。
- 用户可见结果收敛为简短结构判断、1–3 个条件情景和几条盘中关注要点；情景中带理由与反证，不强制展示内部检查栏位。
- 使用条件化语言描述加仓、减仓、追涨、回踩和退出的观察条件；关注点是“若……则观察……”，不是买卖指令。Call、Put、Long Call、Long Put 只作计划/工具术语。
- measured move 只有在锚点、周期和量法清楚时才给；写公式、假设和失效条件，不能把投影当保证目标。
- 当预测事件、触发、周期/窗口、支持证据和反证都明确时，可给本助手宽区间主观概率（常用约 40–50%、50–60%、60–70%）；这是约数和表达区间，不是 Brooks 固定分档、强制上下限或回测胜率。缺口、用户口述或形成中 K 线应明确条件或暂不量化。
- 标的方向事件不等于 Long Call/Long Put 盈利概率；不强制 R:R、仓位、有效期或结果评价，不把未结算交易写成结果。新闻、财报、开盘跳空或时效缺口应扩大不确定性。

## 用户操作 Cycle

以下三阶段用于组织当前用户的做多计划，不声称是 Brooks 官方固定分类：

1. 底部反转 / wedge pop：下跌推动减弱，出现多次测试或小底部区间，再观察向上突破和已完成 1H 做多信号 K。wedge pop 是用户的操作标签；必须把推动、整理边界和突破证据说清楚。
2. 突破后整理 / 二次进场：第一次向上突破得到接受后，等待横盘、小回踩或突破位重测；位置守住并重新出现已完成 1H 做多信号 K时，才进入二次买入考量。
3. Extension / buy climax：明显放量扩张或连续强势上涨接近后期时，不新增追涨；观察已有仓位的减仓或退出条件，以及扩张后的耗尽、横盘或回测。

每个阶段都先过位置门槛，再检查已完成 1H 信号。若关键区域被跌破且不能收回，停止原买入解释并等待重新构造。

## 1. 趋势回踩与第二段

- 识别线索：已有推动腿和方向性摆动，回撤未明显破坏原结构，随后出现原方向的再次推进候选。
- 支持证据：高低点序列仍延续；回撤在前突破点、趋势线或其他已说明的位置获得反应；signal bar 后有沿预期方向的后续推进跟随，回踩守住则作为额外支持证据。
- 反证/失败：回撤变成双向重叠区间；反向强 K 在关键位置出现；突破点被重新收回且没有延续。不要把第二段自动写成趋势确认。
- 1D → 1H：用 1D 标注背景方向和主要摆动，再在 1H 查回撤结束、第二段候选和是否形成新的区间；没有 1H 就不写执行确认。
- 适合生成的盘中关注点：若回踩守住并有 1H 跟随，则观察第二段是否延续；若跌回原结构，则暂停延续解释并重评估。

这里的第二段是走势结构；H2 特指上涨背景的回踩中第二次向上入场尝试，向下对应 L2。两者必须分别记录，不能把任意同向第二次或 H2/L2 代替 second leg。

## 2. 交易区间上下沿突破与失败

- 识别线索：边界清楚且有重叠、双向尝试；价格接近上沿或下沿后出现突破候选，或突破后重新回到区间。
- 支持证据：边界外有收盘接受、后续推进或回踩守住；失败分支则需要外部不能接受并出现反向行为。
- 反证/失败：突破很快回到区间、边界外没有 follow-through，或反向 signal bar 在边缘形成；区间中部的模糊动作不应被命名为边界突破。
- 1D → 1H：1D 提供大区间背景；1H 确认哪一条边界正在测试、是否在外部接受、回踩是否守住。QQQ 双向日内 Set 可将上沿后的延续观察映射为 Call 分支、下沿后的延续观察映射为 Put 分支，但不等于盈利结论。
- 适合生成的盘中关注点：若边界外接受并有跟随，观察回踩；若回到区间，观察另一侧的反转证据，不追写原突破。

## 3. 通道突破与失败

- 识别线索：多数摆动受趋势线和通道线约束，价格测试边界、加速离开通道或跌破趋势线。
- 支持证据：突破后在新区域接受并出现跟随；失败则表现为回到通道、突破段耗尽或反向测试得到延续。
- 反证/失败：只有一根越界 K 线、通道线画法依赖未说明的锚点，或回到原通道后仍无方向。向趋势方向加速突破与跌破趋势线的反向突破是不同事件，不能混写。
- 1D → 1H：1D 判断通道背景和边界；1H 观察越界后的接受、回踩及重新进入通道。先确认是哪一种突破，再生成对应分支。
- 适合生成的盘中关注点：若加速后回踩守住，则观察新趋势腿；若跌破趋势线后反弹失败，则观察反向测试；若重新收回通道，撤销越界解释。

## 4. Micro double top/bottom 与 wedge

- 识别线索：短距离内两次接近的高点或低点，或通常可见三次同向推动（未必形成标准收敛）的楔形候选；必须结合趋势回踩或趋势末端，并放回趋势或区间位置理解。
- 支持证据：第二次测试在有意义的位置出现反应，signal bar 得到跟随，或楔形末端突破后能在外部接受。
- 反证/失败：第二次测试只是区间噪声、突破无跟随、原方向很强且继续推进。Micro double bottom/top 不是自动趋势反转，可以只是小回撤或区间摆动。
- 1D → 1H：1D 只说明更大背景和位置；1H 检查两次测试的相对位置、signal bar 和 follow-through，不把日线一根 K 线当作微型结构。
- 适合生成的盘中关注点：若第二次测试后出现跟随，观察小级别反转是否发展；若跟随缺失或原方向再创新高/低，回到原状态分支。

## 5. Measured move

- 识别线索：存在可以复述起止点的区间、第一段推动腿、突破段或 measuring gap；锚点和周期一致。
- 支持证据：结构两端明确，量法只有一个且后续起点可核对；价格行为仍未触发结构失效。
- 反证/失败：锚点靠猜、周期混用、K 线未完成、结构重新进入原区间或两段失去可比性。此时只写“measured move 待观察”。
- 1D → 1H：选定一个周期后，用该周期内同一结构的锚点独立计算；1D 与 1H 可以分别给参考，但不跨周期混合区间高度、Leg 1 = Leg 2 或突破段锚点。
- 适合生成的盘中关注点：若锚点保持有效，观察价格是否接近该结构投影并出现反应；若失效条件触发，撤销投影并重新判定状态。任何投影都不是保证目标。

量法和概率表达统一遵守 pa-framework.md：不固定点数或 K 线数量；若给主观概率，必须定义事件、触发、周期/窗口、支持证据和反证，不能把标的方向改写成期权盈利率。

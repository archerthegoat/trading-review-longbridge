# 脱敏交易习惯参考

本文件只记录稳定的输出偏好，供 al-brooks-pa 调整表达，不是用户档案、行情数据或交易记录。

- 只分析用户已经预筛选的标的或交易 Set，不做市场扫描或选股。
- 默认只做单边上涨，不从下跌结构自动生成 Put 或做空计划；下跌主要用于判断不买、等待、减仓或退出。
- 日线用于判断 Cycle、市场状态、位置、量价及 EMA10/20；已完成 1H K 线是盘中操作依据。盘前价格和形成中 K 线只用于更新观察状态。
- 当前使用的 Cycle of Price Action 操作模型分为：底部反转 / wedge pop；突破后横盘或小回踩形成的二次进场；extension / buy climax。接近后期扩张时以持仓管理和退出观察为主，不新增追涨。
- 到达缺口、EMA 或突破位不是买点。先判断关键区域是否守住，再等待已完成 1H 做多信号 K；若位置失效，则等待结构重新形成。
- PA、成交量、EMA10 和 EMA20 要在同一数据口径下共同描述；成交量比较必须说明基准，不能只写“放量”。
- 期权术语使用 Call、Put、Long Call、Long Put。
- 关注“若……则观察……”的条件化输出，明确用户自述、数据事实和分析推断，并保留 source、as_of、period、candle_status。
- 保留“考虑”“可能”“观察”等确定程度；用户的可能性表述不能升级为确定的执行计划或行情事实。
- 证据足够且事件定义清楚时接受宽区间的大致主观概率；缺少定义、锚点或数据时说明缺口或暂不量化。
- 不把未结算交易写成结果，不提前评价结果，不强制要求 R:R、仓位、有效期或“最满意”判断。
- 关注清单按“日线阶段与位置｜1H 做多信号 K｜跟随或二次进场｜失效后等待”组织，但不会成为自动执行状态；任何写入仍需用户明确确认。

不得在本参考中加入真实持仓、成交、价格、数量、期权合约、账户、订单/成交 ID、凭据或会话信息。
